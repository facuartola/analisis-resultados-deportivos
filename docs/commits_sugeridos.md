# Mensajes de commit sugeridos

Usar siempre el ID del issue de Jira al inicio del mensaje.

```bash
git add README.md .gitignore
git commit -m "OE-1: Crear documentación inicial y archivo gitignore"

git add datos/resultados_partidos.csv
git commit -m "OE-2: Agregar dataset de resultados deportivos"

git add scripts/analisis_resultados.py
git commit -m "OE-2: Implementar script de análisis de posiciones"

git add resultados/
git commit -m "OE-2: Generar tabla, resumen y gráfico del torneo"

git add README.md
git commit -m "OE-3: Mejorar instrucciones de ejecución del proyecto"
```
